# Website status review

Reviewed **2026-11-12**: **200 entries**, **198 distinct listed URLs**, across **6 categories**. The list contains **180 alive** and **20 defunct** entries. These totals include retained statuses where current checks were inconclusive.

Every listed URL was checked through the web browsing service, following redirects and inspecting product content. Failed requests were retried with canonical domains, official documentation, or project repositories where available. The linked GitHub repositories were also reviewed for explicit archival or maintenance notices. Direct HTTP checks from the local workspace failed for every domain because DNS resolution was unavailable; those failures were excluded from status decisions.

A reachable page alone does not establish that its original service still operates: historical announcements, parked or repurposed domains, and explicitly unmaintained projects remain defunct. Services still running for existing customers remain alive. A failed fetch, a JavaScript shell, or missing readable content is recorded as **inconclusive**, with the previous status retained. This review did not exercise deployments, billing, or authenticated services.

## Notable updates

- Added the 11 projects missing from the webpage; it now matches the README's 200 entries.
- Corrected **Cloud9** to alive: [AWS confirms continued access for existing customers](https://aws.amazon.com/blogs/devops/how-to-migrate-from-aws-cloud9-to-aws-ide-toolkits-or-aws-cloudshell/).

Its [website](https://genezio.com/) and [documentation](https://genezio.com/docs/) now describe AI visibility services; this does not mean the company has closed.
