# Platform Tutorials

This directory will collect step-by-step tutorials on how to use the platforms listed in [Awesome PaaS](../README.md), from setting up an account to deploying and managing an application.

## Available tutorials

No tutorials have been added yet. New guides will be linked here as they are contributed.

## Adding a tutorial

Follow the repository's [contribution guidelines](../CONTRIBUTING.md).

1. Create a Markdown file in this directory with a descriptive, lowercase filename, such as `platform-name-getting-started.md`.
2. Explain what the reader will build and list the prerequisites, including any required account, tools, and costs.
3. Provide step-by-step instructions with commands or examples where useful.
4. Show how to verify the result, troubleshoot common issues, and remove any resources created during the tutorial.
5. Include the date the instructions were last tested and links to the platform's official documentation.
6. Add a link under **Available tutorials**, sorted alphabetically by platform name.
